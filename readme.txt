WordPress icon collection with payment method icons by Pronamic Pay.

== Description ==

WordPress 7.1 introduced the Icon API and the Icon block. This plugin registers a "Pronamic Pay" icon collection with single-colour icons of popular payment methods, such as iDEAL | Wero, Bancontact, PayPal, Apple Pay, Google Pay, Klarna and SEPA.

The icons follow the text colour of the Icon block, so they blend into the design of your website. The plugin also adds a "Payment method icons" block pattern.

All payment method names and marks are trademarks of their respective owners.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the "Plugins" menu in WordPress
