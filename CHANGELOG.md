## [1.0.0] - 2026-11-04

### Added

- Pronamic Pay icon collection with 18 payment method icons for the WordPress 7.1 Icon API.
- Payment method icons block pattern.

### Composer

- Added `automattic/jetpack-autoloader` `v6.0.3`: hardened path handling (security fix). [Changelog](https://github.com/Automattic/jetpack-autoloader/blob/v6.0.3/CHANGELOG.md)
- Added `composer/installers` `v2.3.0`: new installers for Botble, ConcreteCMS and Fork CMS 6, and new Drupal and Moodle types. [Release](https://github.com/composer/installers/releases/tag/v2.3.0)
