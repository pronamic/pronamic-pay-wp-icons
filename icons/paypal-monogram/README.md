# PayPal monogram

![PayPal monogram](paypal-monogram.svg)

WordPress icon name: `pronamic-pay/paypal-monogram`

## Source

- PayPal pictogram: https://www.paypalobjects.com/paypal-ui/pictograms/multicolored/svg/paypal-backed.svg
- Font Awesome PayPal icon: https://fontawesome.com/icons/paypal?f=brands
- Imported from [`assets/paypal-monogram-alt.svg`](https://github.com/pronamic/pronamic-pay-ideal-wero-wp-icon-test/blob/main/assets/paypal-monogram-alt.svg) in the `pronamic-pay-ideal-wero-wp-icon-test` repository.

## Modifications

- Single colour, the fill inherits `currentColor` so the Icon block text colour applies.
- Cleaned up to a single `<path>` element (removed `style`, `data-name` and other attributes WordPress strips anyway).
- Uses `viewBox="0 0 6.35 6.35"` instead of `0 0 24 24` (Inkscape millimetre canvas); renders the same.
