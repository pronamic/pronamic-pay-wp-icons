# Google monogram

![Google monogram](google-monogram.svg)

WordPress icon name: `pronamic-pay/google-monogram`

## Source

- Google Pay brand guidelines: https://developers.google.com/pay/api/web/guides/brand-guidelines
- Imported from [`assets/google-monogram.svg`](https://github.com/pronamic/pronamic-pay-ideal-wero-wp-icon-test/blob/main/assets/google-monogram.svg) in the `pronamic-pay-ideal-wero-wp-icon-test` repository.

## Modifications

- Single colour, the fill inherits `currentColor` so the Icon block text colour applies.
- Cleaned up to a single `<path>` element (removed `style`, `data-name` and other attributes WordPress strips anyway).
