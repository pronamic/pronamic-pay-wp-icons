WordPress icon name: `pronamic-pay/google-pay`

## Source

- Google Pay brand guidelines: https://developers.google.com/pay/api/web/guides/brand-guidelines
- Imported from [`assets/google-pay-mark.svg`](https://github.com/pronamic/pronamic-pay-ideal-wero-wp-icon-test/blob/main/assets/google-pay-mark.svg) in the `pronamic-pay-ideal-wero-wp-icon-test` repository.

## Modifications

- Single colour, the fill inherits `currentColor` so the Icon block text colour applies.
- Cleaned up to a single `<path>` element (removed `style`, `data-name` and other attributes WordPress strips anyway).
